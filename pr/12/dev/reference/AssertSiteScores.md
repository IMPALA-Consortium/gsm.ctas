# Validate CTAS site scores

Validate CTAS site scores

## Usage

``` r
AssertSiteScores(dfSiteScores, strGroupCol)
```

## Arguments

- dfSiteScores:

  `data.frame` CTAS site scores.

- strGroupCol:

  `character` Required grouping column.

## Value

`NULL`, invisibly. Aborts when the input is unusable.
