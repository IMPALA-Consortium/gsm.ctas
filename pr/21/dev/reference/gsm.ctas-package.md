# gsm.ctas: Add CTAS Anomaly Detection to gsm

Integrates the 'ctas' clinical trial anomaly detection statistics engine
into the Good Statistical Monitoring ('gsm') framework. Provides
mappings from SDTM domains into the long-format input 'ctas' expects,
data preparation by data type, and aggregation of 'ctas' site scores
into the gsm analysis contract, together with declarative workflow YAML.
